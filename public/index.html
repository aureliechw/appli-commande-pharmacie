Export ANSM manuel

Par défaut, l'application utilise l'export ANSM récupéré automatiquement chaque jour. Pour utiliser un export plus récent, chargez ici le fichier téléchargé depuis le site de l'ANSM.

Chargez le fichier du jour pour calculer la commande

L'application applique la méthode de réapprovisionnement (déclencheurs FS5/FS6/FS9, compléments, quantités arrondies au multiple de commande) puis croise la liste avec les alertes de disponibilité de l'ANSM.

Le fichier est traité uniquement dans ce navigateur : il n'est envoyé à aucun serveur.

Valider la commande

Vérifiez les fournisseurs à exporter. Un fichier Excel sera généré par laboratoire, ainsi qu'un ZIP qui les regroupe ; ils seront enregistrés dans le dossier de téléchargements du navigateur.

Ajouter un médicament non préconisé

Recherchez parmi les produits du fichier que l'application n'a pas retenus. La ligne ajoutée reprend tous les indicateurs, et la colonne « Motif » indique pourquoi le produit n'avait pas été retenu.
